# Инструкция: сборка iOS-приложения и публикация в App Store

Нативный iOS-проект уже сгенерирован и настроен в папке `ios/` — Capacitor,
bundle ID, разрешения на календарь и иконка приложены. Финальную сборку
и подпись нужно сделать на компьютере с **macOS** — Apple не позволяет
собирать iOS-приложения на Windows/Linux, это требование самой платформы,
а не ограничение конструктора.

## Что уже готово в проекте
- Bundle ID: `ru.hunterdiary.app`, название: «Охотник»
- Нативный проект `ios/App` создан и синхронизирован с `dist/`
- Разрешение на календарь прописано в `Info.plist`:
  `NSCalendarsUsageDescription`, `NSCalendarsFullAccessUsageDescription`
  (для функции «добавить событие охоты в календарь телефона»)
- Политика конфиденциальности: `/privacy`
- Условия использования: `/terms`
- Иконка 1024×1024 для App Store: `public/app-store-assets/ios-icon-1024.png`

## Что нужно на вашей стороне
- **Компьютер с macOS** с установленным **Xcode** (бесплатно, из Mac App Store)
- **Аккаунт Apple Developer Program** — https://developer.apple.com/programs/
  (платный, 99$/год, нужен для публикации в App Store)
- **CocoaPods** — менеджер зависимостей iOS: `sudo gem install cocoapods`

## Шаг 1. Скачайте код проекта
В интерфейсе poehali.dev: **Скачать → Скачать код**

## Шаг 2. Установите зависимости
```bash
cd hunter-app-creation-1
npm install   # или bun install
```
Папка `ios/` уже входит в код проекта.

## Шаг 3. Установите зависимости CocoaPods
```bash
cd ios/App
pod install
cd ../..
```

## Шаг 4. Соберите веб-часть и синхронизируйте с нативным проектом
Каждый раз при изменении кода перед сборкой в Xcode:
```bash
npm run build
npx cap sync ios
```

## Шаг 5. Откройте проект в Xcode
```bash
npx cap open ios
```
Откроется Xcode с файлом `App.xcworkspace`.

## Шаг 6. Настройте подпись приложения
1. В Xcode выберите проект **App** в навигаторе слева
2. Вкладка **Signing & Capabilities**
3. Выберите вашу команду разработчика (**Team**) — она появится после входа
   в Xcode под вашим Apple ID (Xcode → Settings → Accounts)
4. Team ID и Bundle Identifier должны совпадать с тем, что зарегистрировано
   в App Store Connect

## Шаг 7. Создайте карточку приложения в App Store Connect
1. Зайдите на https://appstoreconnect.apple.com
2. **Мои приложения → «+» → Новое приложение**
3. Укажите: платформа iOS, название «Охотник», язык, Bundle ID `ru.hunterdiary.app`,
   SKU (произвольный внутренний код, например `hunter-app-001`)
4. Заполните карточку: описание, категория, иконка 1024×1024
   (`public/app-store-assets/ios-icon-1024.png`)
5. Добавьте скриншоты приложения под нужные размеры экранов (iPhone 6.7",
   6.5", iPad и т.д. — Apple укажет точные требуемые размеры)
6. Укажите ссылку на политику конфиденциальности: `https://ваш-домен/privacy`
7. Заполните раздел **Конфиденциальность данных** (App Privacy) — укажите,
   что приложение запрашивает доступ к календарю

## Шаг 8. Соберите и загрузите билд
1. В Xcode выберите в верхней панели устройство **Any iOS Device (arm64)**
2. Меню **Product → Archive** — дождитесь сборки архива
3. В открывшемся окне Organizer нажмите **Distribute App**
4. Выберите **App Store Connect → Upload**
5. Следуйте мастеру (подпись автоматическая, если Team выбрана верно)
6. Дождитесь завершения загрузки — билд появится в App Store Connect
   через 5-15 минут после обработки Apple

## Шаг 9. Отправьте на модерацию
1. В App Store Connect откройте карточку приложения
2. В разделе **Сборки (Build)** выберите загруженный билд
3. Заполните информацию для проверки (Review Information) — при необходимости
   добавьте тестовый логин, если он нужен модератору
4. Нажмите **Добавить в проверку (Submit for Review)**
5. Модерация Apple обычно занимает 1-3 дня

---

## Почему сборку нельзя сделать автоматически
1. **Только macOS** — Xcode и iOS SDK работают исключительно на компьютерах
   Apple, это ограничение самой Apple, а не конструктора
2. **Подпись сертификатом разработчика** — финальный шаг всегда выполняется
   вручную с вашим Apple Developer аккаунтом, сертификат никогда не должен
   покидать ваше устройство

## Важные напоминания
- Bundle ID везде должен совпадать: `capacitor.config.ts`, Xcode проект
  и карточка в App Store Connect — `ru.hunterdiary.app`
- После любых правок в коде: `npm run build` → `npx cap sync ios` → пересборка в Xcode
- Скриншоты для карточки делайте на реальном iPhone/iPad или в симуляторе Xcode

# Инструкция: публикация Android-приложения в Google Play

Хорошая новость: техническая часть уже готова — тот же нативный проект `android/`,
что использовался для RuStore, подходит и для Google Play без изменений в коде.
Разница только в формате собираемого файла и в шагах внутри Google Play Console.

## Что уже готово и переиспользуется из подготовки к RuStore
- appId: `ru.hunterdiary.app`, название: «Охотник», версия 1.0
- Нативный проект `android/` (Capacitor), иконки, разрешения, загрузочный экран
- targetSdkVersion 36 / minSdkVersion 24 / compileSdkVersion 36 — выше минимальных требований Google Play (targetSdk 34+)
- Иконка 512×512 для карточки: `public/icons/icon-512.png` (без прозрачности — подходит под формат Google Play)
- Баннер-графика 1024×500: `public/app-store-assets/play-feature-graphic.png` — Google Play использует ровно этот же размер
- Скриншоты экранов приложения (1080×1920, формат 9:16 — то, что требует Google Play) уже готовы
  в `public/screenshots-google-play/`: главная, календарь, дневник охот, оружейный сейф, карта охот —
  дополнительно снимать вручную не нужно
- Политика конфиденциальности: `/privacy`
- Условия использования: `/terms`
- Google-сервисов (Firebase и т.п.) в проекте нет — не помешают модерации

## Главное отличие от RuStore: формат файла
- RuStore на первом релизе принимает **.apk**
- Google Play **всегда требует .aab** (Android App Bundle) — даже для самой первой публикации.
  Собирать нужно отдельно, .apk из инструкции для RuStore сюда не подойдёт.

## Шаг 1. Требования на компьютере
- **Node.js версии 22+**
- **Android Studio** (https://developer.android.com/studio)
- Аккаунт разработчика в **Google Play Console** — https://play.google.com/console
  (разовый платёж 25$, привязка карты и подтверждение личности — занимает от пары часов до нескольких дней)

## Шаг 2. Скачайте код проекта
В интерфейсе poehali.dev: **Скачать → Скачать код**, затем:
```bash
cd hunter-app-creation-1
npm install   # или bun install
```
Папка `android/` уже входит в код проекта.

## Шаг 3. Соберите веб-часть и синхронизируйте с нативным проектом
```bash
npm run build
npx cap sync android
```

## Шаг 4. Соберите AAB-файл в Android Studio
```bash
npx cap open android
```
Дальше:
1. Дождитесь синхронизации Gradle
2. Меню **Build → Generate Signed Bundle / APK**
3. Выберите **Android App Bundle (.aab)** — не APK
4. Создайте новый ключ подписи (Keystore) через мастер, **если ещё нет keystore от RuStore —
   можно использовать один и тот же файл для обеих площадок**, тогда сохраните пароли и файл в надёжном месте
5. Соберите **Release**-версию

## Шаг 5. Публикация в Google Play Console
1. **Создать приложение** → укажите название «Охотник», язык — русский, тип — приложение, бесплатное
2. **Настройка приложения → Основная карточка магазина**:
   - Иконка 512×512 — `public/icons/icon-512.png`
   - Featured-графика 1024×500 — `public/app-store-assets/play-feature-graphic.png`
   - Скриншоты телефона: загрузите готовые файлы из `public/screenshots-google-play/`
     (5 штук, 1080×1920 — соответствуют требованиям Google Play, минимум 2 обязательны)
   - Категория: «Спорт» или «Образ жизни», короткое и полное описание
3. **Раздел «Безопасность данных» (Data safety)** — обязателен для Google Play, в RuStore его нет.
   Нужно честно указать: какие данные собирает приложение (например, аккаунт, геолокация — если
   используется карта охот) и как они используются. Ссылку на политику конфиденциальности возьмите
   отсюда: `https://ваш-домен/privacy`
4. **Контентный рейтинг (Content rating)** — пройдите опросник (для дневника охотника обычно
   базовая категория без ограничений, но встречаются вопросы про оружие/охоту — отвечайте честно)
5. **Целевая аудитория и содержание** — укажите возрастную группу
6. **Раздел «Релизы» → Производственный трек (Production) → Создать релиз**
   — загрузите собранный `.aab`-файл из Шага 4
7. Заполните примечания к релизу (release notes)
8. Отправьте на проверку — модерация Google Play обычно занимает от нескольких часов до нескольких дней

## Важные напоминания
- **Keystore-файл нельзя терять** — без него не получится выпускать обновления приложения
- Google Play использует свою систему подписи (Play App Signing) — при первой загрузке .aab
  система предложит зарегистрировать ключ, соглашайтесь
- После любых правок в коде: `npm run build` → `npx cap sync android` → пересборка в Android Studio
- Bundle ID/appId должен совпадать везде: `capacitor.config.ts` и карточка в Google Play Console —
  `ru.hunterdiary.app`. Один и тот же appId можно использовать и в RuStore, и в Google Play —
  это разные площадки, конфликта не будет
- Раздел «Безопасность данных» и опросник контент-рейтинга — специфика именно Google Play,
  в RuStore их нет
